# Assignment 5: Shader Graphs — Lightsaber

A URP lightsaber built with Shader Graph and Bloom! I turned it into a double-bladed saber that you swing with the mouse, throw, and Force-pull back, with sound effects and an unstable,
flickering "Kylo Ren"-style blade shader.


## How to run

Open the project in Unity, open `Assets/Scenes/SampleScene.unity`, and press Play.
Click inside the Game view so it gets keyboard input.

## Controls

- Mouse: swing the saber
- Space: turn the blades on/off
- T: throw the saber
- F: pull it back
